FBox

Training template

Задача

Клиент разработал формат тренировок на основе видео: упражнения сопровождаются таймерами, текстовыми подсказками, музыкой и звуковыми сигналами. Нужно было подготовить систему для большого количества тренировок с разными упражнениями и сделать так, чтобы текст можно было менять без ручной правки десятков слоёв в After Effects.

Подход

Я собрал шаблон, в котором повторяющийся текст и основные параметры меняются централизованно. Это ускорило подготовку новых тренировок и снизило вероятность ошибок при редактировании. В процессе работы стало понятно, что для управления большим количеством текстовых слоёв нужен отдельный инструмент. Так появился Text IMP — ему посвящён следующий кейс.

Полное видео показать не могу, поэтому здесь — несколько кадров из проекта.

Text IMP

Custom AE Tool

Задача

Для серии видео-тренировок был нужен шаблон с большим количеством текста, который регулярно менялся от ролика к ролику.

Подход

Чтобы не редактировать десятки текстовых слоёв вручную, я собрал инструмент для After Effects, который позволяет менять весь текст проекта из одного окна.

Почему свой инструмент

Готовые решения не полностью подходили под этот workflow, а часть коммерческих инструментов была неудобна из-за региональных и платёжных ограничений. Для конкретной задачи оказалось проще собрать собственный инструмент.
