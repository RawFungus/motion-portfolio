# Motion Portfolio — GitHub Pages

Статическое портфолио для GitHub Pages без сборщика и внешних зависимостей.

## Публикация

1. Загрузите содержимое репозитория в ветку `main`.
2. Откройте `Settings → Pages`.
3. Выберите `Deploy from a branch`.
4. Выберите `main` и `/ (root)`.
5. Сохраните настройки.

## Основные файлы

- `index.html` — структура, тексты и разметка проектов.
- `css/style.css` — сетка, адаптив, large-screen autoscale и fullscreen viewer.
- `js/main.js` — подсветка навигации, autoplay/pause видео, принудительный mute, анимация гайки и fullscreen-галереи.
- `assets/images/` — изображения проектов и SVG.
- `assets/video/` — MP4-видео проектов.

## Медиа

Подробности по структуре и замене файлов находятся в `assets/README.md`.

Медиа внутри одного `.media-area` автоматически считаются одной fullscreen-галереей: при открытии их можно листать стрелками, не переходя в другой проект.

Все видео на странице и во fullscreen viewer принудительно воспроизводятся без звука.

Страница использует относительные пути и корректно работает в GitHub Pages-проекте вида `username.github.io/portfolio/`.
